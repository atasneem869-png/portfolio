# Tasneem Ashraf — Portfolio

This folder is ready to publish with GitHub Pages.

## Structure

- `index.html` — main portfolio page
- `CV.pdf` — CV
- `profile.jpeg` — profile photo
- `jewelry/` — Jewelry Website project

## GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder (not the outer ZIP folder).
3. In GitHub: Settings → Pages.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. GitHub will give you a public link ending in `github.io`.

The portfolio is now the root `index.html`, so the GitHub Pages link opens the portfolio directly.
